## Privacy / Security

- The checked manifest requests `INTERNET`, `ACCESS_NETWORK_STATE`, `ACCESS_WIFI_STATE`, and `CHANGE_WIFI_MULTICAST_STATE`. These correspond to user-initiated Ping/DNS/TCP/Traceroute/LAN/WoL and Wi-Fi/mDNS discovery. No location, nearby-device, account, ads, or analytics permission was found in the checked manifests.
- History and Saved Device Profiles (including custom names and WoL config) use local Room. `allowBackup=false`. No analytics/cloud-upload SDK or automatic report upload was identified in the Gradle/source review. Explicit user-initiated PDF save/share is a separate export action; sharing can send the user's chosen report to another app.
- Network probes necessarily contact chosen targets; mDNS/SSDP/UPnP and WoL send LAN traffic. `usesCleartextTraffic=true` exists for the local UPnP HTTP description path; its broad app-level scope is worth a later policy review, but is not by itself evidence of uploading inventory. The UPnP fetch path validates advertised locations and disables redirects.
- `git ls-files` found no tracked `local.properties`, `key.properties`, `*.jks`, `*.keystore`, or private-key file. A targeted tracked-file pattern scan found no known API-key/token/private-key signature. Local `key.properties` and keystore are ignored. Pattern scans are not a complete secrets audit; do not print or commit signing values.
- No confirmed secret/privacy release blocker was found. No runtime data-exfiltration test was conducted.

1. This workstation has no attached Sony device for independent reproduction; the maintainer reports the exact signed v0.5.0 APK passed the final Sony Xperia 1 VII / Android 16 regression.

5. VAIO wake compatibility/settings are unresolved per maintainer, while one main machine has successfully woken. WoL does not guarantee wake for every device.
