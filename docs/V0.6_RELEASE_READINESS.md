# LinkBeacon v0.6.0 Release Readiness

Audit date: 2026-09-18 (Asia/Shanghai)

## Executive Summary

LinkBeacon v0.6.0 is **Feature Complete** and the runtime is **Frozen for
RC1**. The bilingual implementation, compatibility work, repository
documentation, automated gates, signed Release build, signing identity, and
16 KB compatibility checks pass.

The exact signed RC1 APK identified below has passed the authorized signed
v0.5.0 → v0.6.0 RC1 upgrade and full bilingual regression on Android 12.
Sony XQ-AT72 / Android 12 / API 31 is the selected representative full-RC
device. Under the accepted release policy, this satisfies the final device RC
gate. **RC1 is Release Ready.** No v0.6.0 Tag or GitHub Release has been
created by this readiness task.

## Formal Scope

- One APK with English and Simplified Chinese.
- Follow system language and explicit App Language Settings.
- Android 12, Android 13, and Android 16 compatibility.
- Localized core UI, dynamic diagnosis, History, text reports, PDF reports,
  Copy, and Share output.
- Backward-compatible presentation of legacy History records.
- English-primary and Simplified-Chinese GitHub documentation.

The frozen scope excludes additional languages, Stable Device Identity,
First Seen / Last Seen, Wi-Fi Analyzer, multi-network management, and any new
network tool or product capability.
