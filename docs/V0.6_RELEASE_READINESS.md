# LinkBeacon v0.6.0 Release Readiness

Audit date: 2026-09-18 (Asia/Shanghai)

## Executive Summary

LinkBeacon v0.6.0 is **Feature Complete** and the runtime is **Frozen for
RC1**. The bilingual implementation, compatibility work, repository
documentation, automated gates, signed Release build, signing identity, and
16 KB compatibility checks pass.

The version is **not yet Release Ready**. The exact signed RC1 APK identified
below still requires the separately authorized full bilingual regression on
Android 12, Android 13, and Android 16. No v0.6.0 Tag or GitHub Release has
been created.

## Formal Scope

- One APK with English and Simplified Chinese.
- Follow system language and explicit App Language Settings.
- Android 12, Android 13, and Android 16 compatibility.
- Localized core UI, dynamic diagnosis, History, text reports, PDF reports,
  Copy, and Share output.
- Backward-compatible presentation of legacy History records.
- English-primary and Simplified-Chinese GitHub documentation.

The frozen scope excludes additional languages, Stable Device Identity,
First Seen / Last Seen, Wi-Fi Analyzer, multi-network management, and any new
network tool or product capability.

## Completed Scope

- Application identity remains `com.networktoolbox`; launcher name remains
  `LinkBeacon`.
- Version metadata is `versionName=0.6.0`, `versionCode=6`, `minSdk=31`,
  `targetSdk=36`, and `compileSdk=36`.
- Version codes 1 through 5 are already associated with v0.1.0 through
  v0.5.0; version code 6 is the next unused monotonic value.
- Supported resources remain limited to the English base resources and
  `zh-Hans`; the APK reports only the base locale and `zh-Hans`.
- No production Kotlin, Room schema, dependency, permission, network probe,
  detector, or product-scope change is included in this RC preparation.

## Localization Coverage

- The 11 shipped UI/resource modules contain 1,109 English resource units and
  1,109 Simplified-Chinese resource units.
- Unit tests enforce key, plural-quantity, placeholder, and format parity.
- The English defaults are checked for unintended Chinese UI text.
- Static residual review found no release-blocking hard-coded user-facing
  locale text. Remaining literals are technical protocol names, symbols,
  examples, tests, or intentional legacy/fallback data.
- App Language Settings supports English, Simplified Chinese, and Follow
  system only. Unsupported locales fall back to English without claiming
  another translation.

## Legacy Compatibility

- No Room schema or migration changed in Task 086.
- Existing History, Saved Devices, Favorites, Custom Names, and Wake-on-LAN
  configuration remain on their current compatible data paths.

## RC Gate

Current state: **BLOCKED / PENDING DEVICE REGRESSION; HOLD for public release**.

The repository, metadata, automated gates, signing identity, artifact identity,
and alignment checks permit RC1 to enter device regression, but Task 087 has not
completed Android 12/13/16 acceptance. No runtime code may change while results
are attributed to this checksum. A runtime change requires a rebuild and a new
RC number/checksum.
