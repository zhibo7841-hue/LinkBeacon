## RDAP IP and security

IANA IPv4/IPv6 service selection uses longest CIDR prefix, independently of
directory order and address family. Existing HTTPS-only authority/redirect
rules, no automatic retry, public DNS-answer/connected-peer validation,
captured active Network, VPN routing and fail-closed proxy/PAC handling remain.
No new arbitrary service URL or ASN query is accepted.

The response must be a conforming `ip network`, have the expected IP version
and contain the queried address within its actual returned start/end range.
Display actual range, network name/handle, explicitly organization-kind vCard
name, country if supplied, statuses and supported event dates. No personal
contact name is substituted for an organization. Missing IP fields are omitted.
The country note explicitly distinguishes registration region from geolocation.

Existing bounds: 20 s total, 3 s DNS/connect, 5 s read, 1 MiB decoded result,
512 KiB directory, 4 total request attempts including directory work, at most
3 accepted redirects, bounded JSON depth/node count. No security limit changed.

## WHOIS behavior and limits

Reviewed [IANA .com](https://www.iana.org/domains/root/db/com.html),
[.net](https://www.iana.org/domains/root/db/net.html) and
[.cn](https://www.iana.org/domains/root/db/cn.html) records supply the allowlist:
`.com`/`.net` use `whois.verisign-grs.com`; `.cn` uses `whois.cnnic.cn`.
The current [.uk record](https://www.iana.org/domains/root/db/uk.html) lists no
WHOIS server, so it is not enabled. Do not invent a server from the TLD name.

- [RFC 3912](https://www.rfc-editor.org/info/rfc3912/): ASCII A-label query plus
  CRLF over plaintext TCP 43; read until EOF within the bounds below.
- One user action, one socket/address attempt; no server rotation, retry,
  arbitrary server input, referral following or RDAP fallback.
- Captured-Network socket, public pinned DNS answers and peer verification.
  A configured unverifiable proxy/PAC path stops the query.
- 15 s whole operation, 3 s connect, 5 s read, maximum 65536 response bytes.
- Strict UTF-8 (including ASCII); unsupported encodings, malformed bytes,
  forbidden controls/bidi formatting and oversized text are rejected.
- Coroutine cancellation closes the socket and waits for its I/O worker;
  active-network invalidation also closes it. No per-session executor is
  created. The shared coroutine dispatcher thread pool is not shut down.
- First actual WHOIS action shows the concise plaintext/privacy disclosure.
  Consent is remembered only in the current ViewModel, per protocol; Activity
  recreation does not query or repeat the disclosure. No extra conversion dialog.
- Valid plaintext means **WHOIS response received**, not standardized success
  of registration/availability/ownership. Rate-limit, refusal, referral and
  no-match words are not parsed into invented RDAP status codes. Raw text stays
  inert in expandable details; no contact links/actions or response logging.

## Privacy, preservation and artifacts

registry over HTTPS; explicit WHOIS sends the extracted domain in plaintext to

## Remaining limits and next action

responses; no referral completion or standardized record/availability inference.
An unresponsive first resolved address is not retried on another address.
ICANN PSL snapshots can age; unknown TLDs are deliberately unsupported until a
reviewed update. RDAP redirects remain restricted to the selected directory
query URLs; some services' alternative canonical paths may be rejected safely.
No ASN, GeoIP, reputation, purchasing, new export or History integration.
