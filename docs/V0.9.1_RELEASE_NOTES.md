# LinkBeacon v0.9.1

Status: release-notes draft for the maintenance release candidate; not released.

## Privacy-policy access

- Open the published full privacy policy from the app's Privacy & Data page.
- Open the English or Simplified Chinese policy matching the app language.
- Read clearer summaries of local storage, functional network requests,
  Wi-Fi/location-related access, and deliberate exports/sharing.
- Receive helpful feedback if a browser cannot open the policy; bundled
  summaries remain readable offline.
- Copy the policy link with explicit success or failure feedback.

No network-tool capability, permission, SDK, database migration or data
collection is added in this maintenance release.

## Requirements and status

Android 12 / API 31 or later. Application ID remains `com.networktoolbox`.
v0.9.0 remains the latest published stable version. A prepared signed candidate
is not a completed representative RC regression, a published GitHub Release,
or approval of Google Play signing or submission.
