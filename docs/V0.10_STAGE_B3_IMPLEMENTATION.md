## Implementation and ownership

`feature:rdap` owns input, first-action disclosure, cancellation and transient
result state. App DI supplies the Android ICU normalizer and singleton lookup.
Tools / Resolution & Services exposes Domain Registration / 域名注册查询.
Home quick tools and existing DNS/TLS/Website pages are unchanged.

```text
RdapViewModel -> RunRdapLookup / DefaultRdapLookup
  -> reviewed bootstrap selection / RdapEndpointPolicy
  -> AndroidRdapTransport (captured active Network + cancellable DNS/HTTP)
  -> bounded UTF-8 JSON -> RdapResponseParser -> RdapResult
```

`RdapDomain`, `RdapRegistration`, typed `RdapStatus`, bootstrap provenance and
`RdapResult` carry only this tool's facts. There is no History recorder,
device repository, diagnosis analyzer or export invocation in this chain.

## Exact domain and IDNA

Android ICU UTS #46 uses STD3, BiDi, ContextJ/ContextO and nontransitional
ASCII/Unicode conversion, with an A-label round trip. Input validation is
offline. Uppercase and one terminal root dot normalize; Unicode display and
ASCII query forms remain available. URLs, credentials, paths, query/fragment,
IP literals, local/single-label names, empty/oversized labels, wildcard,
underscore, malformed punycode, controls and invalid Unicode are rejected.
The complete normalized domain is queried. No PSL/eTLD+1 or parent-domain
guessing is performed.

## Transport security and resource limits

The installed OkHttp 5.4.0 library is reused, without changing the existing
headers-only website transport. GET, system TLS trust/hostname checks and
`Accept: application/rdap+json` are used. Bootstrap uses `application/json`.
No cookie jar, authentication, credential headers or HTTP cache is enabled.
No automatic retry, alternate-provider fallback, HTML scraping or JSON link
follow-up exists. HTTP/1.1 and per-request pools avoid cross-host coalescing.
503 Retry-After cannot cause OkHttp's internal repeat.

| Shared budget | Implemented limit |
| --- | --- |
| User actions | One in-flight lookup, application singleton mutex |
| Entire action | 20 seconds, including bootstrap/DNS/body/parse |
| Connect / read / DNS | 3 / 5 / 3 seconds, within overall cancellation |
| HTTP attempts | Four total, including refresh and redirect attempts |
| Redirects | Three; loop rejection; same exact object under selected IANA bases |
| Decoded body | RDAP 1 MiB; bootstrap 512 KiB |
| JSON | Depth 32, nodes 50,000, strings 65,536 UTF-16 units, numbers 64 chars |

Content-Length is checked when present; actual decoded streamed reads stop
at the cap plus one detection byte, including gzip/chunked input. Calls are
cancelled before body close so discarded error/oversized bodies cannot be
silently drained outside this policy. Unknown JSON fields receive the same
limits. Malformed UTF-8, escapes, surrogates, duplicate members, number grammar
and trailing data are rejected. The parser is small pure Kotlin with fixtures;
it is an implementation choice differing from the earlier streaming-library
candidate, and remains an explicit independent-review item.

DNS runs through cancellable `DnsResolver` on the captured active Network.
Every returned address must meet the public-address policy; only that frozen
list is supplied to OkHttp. The planned route and actual socket peer are
checked against the same list before request headers are sent. Private,
loopback, link-local, CGNAT, documentation, benchmark/Fake-IP, multicast and
unsupported special address paths are stopped. A safe redirect must select
the same exact domain object under an IANA-listed equivalent base; arbitrary
response links, userinfo, query tokens, private targets and HTTP are rejected.

Active VPN routing is retained by using the active Network. System proxy/PAC
paths fail closed as `PROXY_UNSUPPORTED`, before HTTP/DNS, because this version
cannot establish the upstream socket destination safely. It does not bypass
a configured proxy or claim knowledge of the server IP behind one. VPN
transport is observed, not a claim about a specific VPN app or its hidden
underlying network. Public Android callbacks detect active-network handle,
transport, interface, link addresses, routes, configured DNS/Private DNS and
proxy changes. A VPN that hides an underlying path change while
exposing identical capabilities cannot be proven stable by these APIs.

Stop, navigation away or genuine backgrounding cancels the job; configuration
recreation retains the owner. Session close cancels DNS/Call, evicts owned
connections and unregisters its callback. Default-network change stops work
and late results are rejected. The ViewModel additionally checks generation
and coroutine activity. No executor is shut down per callback/session.

## Parsing and presentation

Success requires a valid domain RDAP object matching the entire A-label query
and RDAP conformance. The mapper accepts provided registrar `fn` for the
registrar role, valid dated registration/change/expiration events, statuses,
nameservers and `delegationSigned`. Missing fields remain missing; an explicit
redacted array is shown as restricted. No registrant name, email, phone,
address, ownership or purchase inference is mapped. Bounded service notices
are plain Compose text, never HTML, active links or WebView content.

HTTP 400, 401/403, 404, 429 and 5xx have distinct states. 404 describes the
exact object only, not domain availability. 429 does not trigger another
service or WHOIS request. DNS, TLS, timeout, cancellation, changed network,
unsafe redirect/destination, bootstrap and malformed/oversized responses
remain distinct. Details show selected URL, actual HTTP status when one
exists, time, duration, attempt count and bootstrap provenance. A selected
source on a blocked attempt does not assert that HTTP was actually sent.

The default EN/zh screen has one input/action and major registration facts;
technical fields are folded. Running phases come from actual work. The first
valid query needs explicit external-service disclosure confirmation. No
request is made by input validation, opening the tool, locale changes,
Activity recreation, History or result expansion.
