# LinkBeacon v0.6.0

LinkBeacon v0.6.0 is the full bilingual release.

## Highlights

- Full English and Simplified Chinese support.
- Follow the system language or choose a language manually in the app.
- Localized network tools and Device Center.
- Localized automatic diagnosis, findings, explanations, and troubleshooting guidance.
- Localized History, copied text reports, saved PDF reports, and shared PDF reports.
- Improved language-switch and Activity-recreation reliability.

## Compatibility

- Requires Android 12 or later.
- Existing v0.5.0 users can upgrade directly without uninstalling or clearing data.
- History, Saved Devices, Favorites, Custom Names, and Wake-on-LAN configuration remain compatible.
- Legacy History text is preserved when an older record does not contain enough structured data for safe localization.

## Privacy

- No ads.
- No account required.
- Local-first storage.
- Diagnostic data is not uploaded to a cloud service.
