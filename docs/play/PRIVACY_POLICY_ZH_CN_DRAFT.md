## 1. 应用与开发者

LinkBeacon 是 LanYun Studio 开发的开源 Android 网络分析与故障排查工具箱，包名为 `com.networktoolbox`。

## 2. 联系方式

拟用公开支持及隐私联系方式为 **[PUBLIC_SUPPORT_EMAIL_TO_CONFIRM]**，发布前必须替换此占位符。应用没有账号系统或开发者托管的用户数据库，因此不提供在线账号数据删除服务。

## 3. 提供的服务

应用提供网络信息、Ping、DNS Lookup、TCP 检测与 TCP 端口扫描、IPv4 路由追踪、局域网 IPv4 设备发现、设备中心、Wake-on-LAN、Wi-Fi 分析、SSL/TLS 检查、网站诊断及自动网络诊断。结果用于说明观察到的现象和可能原因，不会自动修复网络，也不保证确定唯一故障原因。

## 4. Android 权限

互联网权限用于网络检测；网络及 Wi-Fi 状态权限用于显示网络信息；修改 Wi-Fi 状态权限用于用户主动刷新 Wi-Fi 观察；组播权限用于本地服务发现。应用同时请求精确及大致位置权限，以满足 Android 的 Wi-Fi 访问要求。当前版本没有声明后台位置、通讯录、相机、麦克风或广泛存储权限。

你可以拒绝位置权限，此时附近 Wi-Fi 观察受限。其他工具仍可使用，但受各自网络条件约束。拒绝权限不会触发绕过 Android 限制的行为。

## 5. Wi-Fi 与位置相关信息

在 Android 允许的情况下，Wi-Fi Analyzer 读取当前及附近 Wi-Fi 名称（SSID）、接入点标识（BSSID）、信号测量、频率/信道、安全信息及观察时间戳。这些信息在本机用于解释 Wi-Fi 环境。已审阅的实现不直接读取 GPS 经纬度，也不维护 GPS 位置历史。

应用使用的扫描相关 API 需要精确位置权限并开启系统定位服务；仅大致位置授权可能不够。读取位置相关的 Wi-Fi 信息并不等于读取 GPS 坐标。应用读取已有缓存观察，在用户请求时刷新扫描，没有定时周期扫描循环。页面仍打开但应用转到屏幕外时，连接回调或已开始的系统扫描可能继续完成，因此不承诺完全没有后台回调。

## 6. 在本机处理的网络信息

应用可以处理本地/公网 IP、前缀、网关、DNS 配置、网络类型/接口、VPN 和 Private DNS 状态、系统联网验证、局域网设备及服务响应。Wi-Fi Analyzer 没有专门的附近接入点历史数据库。当前观察可能保留在内存中，直到被替换或进程结束。

## 7. 发往设备外的请求

网络工具会发送完成你启动的操作所需的数据包或请求。域名可能发给系统 DNS 解析链路；Private DNS 或 VPN 会影响 DNS 路由。目标和中间网络可以观察源 IP、目的地址、端口及请求时间。

网站诊断向输入的网站及支持的重定向目标发送 HTTP 或 HTTPS 请求。即使结果中隐藏了查询参数，URL 路径及查询参数仍会发送给目标。执行请求时移除 URL 片段，拒绝包含用户名/密码凭据的 URL。此类探测不会额外添加授权请求头或维护 Cookie 存储；HTTP User-Agent 包含 LinkBeacon 及应用版本。

自动诊断在你启动后选择公共测试目标，包括 `223.5.5.5:443` / `1.1.1.1:443` 辅助 TCP 探测和 example.com DNS/域名检查。这些请求不会把整份诊断报告或本地设备清单发给上述目标。本地发现使用可达性/TCP、mDNS/SSDP/UPnP，以及适用时的反向 DNS；反向 DNS 可能访问局域网之外的解析器。Wake-on-LAN 把选定 MAC 放入本地唤醒数据包。

当前版本未发现开发者运营的诊断资料上传后台，但这不表示所有流量都留在手机中。目标、DNS、代理、VPN、选定的文档或分享服务会处理各自流量，并可能按其政策保留日志。绑定本地网络的发现/WoL 流量可能使用实际物理网络，而不是 VPN 隧道。

## 8. 本地历史与设备资料

受支持的已完成检测及报告保存在应用私有的 Room 数据库中。历史可能包含目标、IP、DNS 记录、耗时、错误、网络事实及报告解释。已保存设备资料可以包含地址、可获取的标识及发现名称、自定义名称、设备类型、备注、收藏状态、唤醒配置和时间戳。

旧版诊断历史可能包含 Wi-Fi 名称。新版精简诊断快照没有该字段，但升级不会自动删除旧记录。设备网络范围可能包含 Wi-Fi/网络事实的哈希；哈希不保证匿名。语言偏好在本机保存，或由 Android 单应用语言系统管理。应用没有云同步功能。

## 9. 导出与分享

复制、保存 PDF 和 Android 分享仅在你主动操作时执行。报告可能包含 IP、域名、DNS 配置及其他网络细节，分享前请审阅。应用文件提供器为选定的分享流程授予报告访问权限；你选择的文档提供器或接收应用可能上传或保留副本。剪贴板处理取决于 Android 及其他有权访问的软件。

网站历史不保存 URL 查询参数和片段，但可以保留路径、主机、选定响应头和网络环境。这种有限脱敏不等于对报告、设备资料或 URL 完整匿名化。保存 PDF、复制或分享不会自动去除上述信息。

## 10. 依赖与诊断日志

应用使用 Android/AndroidX、Kotlin、Room、Hilt 和 OkHttp/Okio 完成界面、存储及网络操作。已审阅的正式依赖和应用代码中未发现广告、统计、专用用户追踪或自动远程崩溃报告集成。系统管理的服务，包括 AndroidX EmojiCompat 使用的可下载字体提供器，可能有各自行为；本次审阅没有独立抓包验证其网络活动。

Android 本地诊断日志可能包含有长度限制的网络地址、服务地址及错误/状态信息，包括 UPnP 诊断。应用不会自动把这些日志发给开发者服务器。若你另行向支持人员提供日志，请先检查并移除敏感细节。

## 11. 保留期限

应用历史和已保存设备资料没有自动到期机制，直到你删除或移除应用本地存储。当前 Wi-Fi 观察是临时数据，不是持久接入点时间线。分享 PDF 可能保留在应用缓存，直到后续分享清理、系统清理缓存或移除应用；不承诺固定到期时间。Android 日志保留由系统控制。

Manifest 关闭了应用的标准自动备份选项，但部分 Android 厂商仍可能提供设备间迁移，不能保证系统迁移过程永远不传输应用数据。你、接收方或外部服务器创建的副本受各自保留方式约束。

## 12. 删除方式

你可以删除单条历史，或确认清空历史。已保存设备单独管理，可以删除；仅取消收藏可能保留其他设备资料字段。Android 的清除应用存储或卸载会移除应用自己的本地存储。这些操作不会删除已导出的 PDF、剪贴板副本、接收方数据或目标服务器日志。本地删除不是经认证的安全擦除过程，应用无法替独立目标或接收方删除其数据。

## 13. 信息保护

数据库位于 Android 应用沙盒保护的私有存储中，没有额外的数据库加密。分享使用限定范围的文件提供器访问。TLS/HTTPS 检查使用平台安全检查，但 HTTP、DNS、本地发现、唤醒数据包及其他探测并非全部加密。请避免检测含秘密的 URL 或在备注中填写秘密。本文件不宣称独立安全认证或绝对匿名保证。

## 14. 账号与儿童

应用无需 LinkBeacon 账号，没有应用内账号创建或广告，也没有应用内付款信息读取器。拟采用的 Google Play 付费下载由 Google Play 处理，而非应用付款表单。本产品是通用网络工具，不专门面向儿童设计。商店目标年龄声明仍需维护者确认；本草案不宣称已加入儿童项目或获得年龄评级认证。
