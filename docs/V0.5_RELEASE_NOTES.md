# LinkBeacon v0.5.0

NetworkToolbox is now LinkBeacon.

This release candidate brings the product's visual refresh and local device
management experience together while keeping network observations and reports
on the device.

## Highlights

- New Home / Tools / Devices navigation and a compact app Drawer.
- Device Center with saved devices, Favorites, Custom Names, and Device Details.
- Search and filters for saved/current Device Center entries.
- Manual local Wake-on-LAN from Device Detail and Quick Wake for eligible saved profiles.
- Automatic Diagnostics and readable Diagnostic Reports.
- Local History with report reopening, PDF save, and PDF sharing.
- Navigation, Back behavior, and scroll-state polish across the app.

## Privacy and access

- Local-first: network results, History, and saved device data remain on the device.
- No ads.
- No account required.
- Requires Android 12 (API 31) or later.

## Compatibility

The Android application ID remains `com.networktoolbox` so existing v0.4
installations can upgrade without losing History, saved devices, Favorites,
Custom Names, or Wake-on-LAN configuration.

This is a release-notes draft for maintainer RC testing. It has not been
