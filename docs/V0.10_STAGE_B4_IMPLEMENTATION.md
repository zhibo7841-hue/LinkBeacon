## Entry points and data flow

Completed SSL/TLS and Website results, and compatible restored Schema 1
History details, now offer **Export results / 导出结果**. A user must open
the dialog and choose Copy, Save TXT, Save Markdown, Save PDF, or Share PDF.
Loading, absent, incompatible, stopped, and unusable snapshots expose no
export action. No automatic export or background upload exists.

```text
Completed result / Schema 1 restored snapshot
  -> WebExportSource
  -> WebExportMapper.freeze(source, language, export time)
  -> immutable WebExportDocument (allowlisted, localized, redacted strings)
  -> TXT / Markdown / native Android PDF
  -> clipboard / actual SAF CreateDocument / read-granted FileProvider chooser
```

The renderer and delivery owner cannot access an Engine, Analyzer, History
repository, or raw result through the frozen document. History recovery
uses the existing snapshot resolver. Export does not refresh missing data.
TLS's existing Completed UI state now carries its completion observation
time; original History serialization and the check algorithm are unchanged.

## Projection and privacy

All formats consume the same frozen document. Copy is the TXT representation.
Markdown escapes formatting delimiters rather than accepting raw Markdown
from targets or responses. PDF accepts only the redacted document.

Preserved evidence includes:

- Syntactically public selected host / port, with safe URL origin only.
- Original observation times, separate actual export time, live vs saved source.
- Overall and per-stage observed statuses / durations, real HTTP status,
  HTTP planned / actual transport, direct TLS socket path, VPN presence.
- TLS protocol / cipher / ALPN allowlist, trust and hostname outcomes,
  presented chain count, certificate validity dates / status and self-sign observation.
- Closed failure / finding / recommendation codes from the snapshot.

Policy 1 removes userinfo, nonroot paths, query / fragment, sensitive Location
components, local / numeric hosts, private network identifiers, interface /
SSID / BSSID / DNS / proxy / PAC identities, credentials, arbitrary headers,
uncontrolled error text, finding arguments and certificate DN / SAN values.
Content-Type preserves only a closed list of standard media types, without
parameters; even a syntactically valid custom MIME token is redacted.
All numeric connection and DNS candidate addresses are conservatively omitted,
including public ones. No DNS lookup is made to classify a host. Public-name
eligibility is syntactic, with local / reserved suffix rejection; it is not a
claim that the exported hostname resolves publicly. Public targets and observed
facts can still identify a service, so the dialog and document advise review
before sharing. There is no unredacted mode.

`Not measured / 未检测`, `Failed / 检测失败`, `Not recorded / 字段缺失`,
and `Redacted / 已脱敏` remain distinct. HTTP failures without a response are
not relabeled as unmeasured. Unknown free-form protocol values fail closed.
Saved fields do not acquire invented DNS TTL, responding server, certificate
DER / fingerprint, or new observations. Presented chain data is preferred
over appending a potentially duplicate restored leaf certificate.

## Delivery and lifecycle

- TXT / Markdown MIME: `text/plain` / `text/markdown`; PDF: `application/pdf`.
- Filenames contain a UUID, no target or URL. Save uses Android's real
  `CreateDocument`; Share uses `EXTRA_STREAM`, `ClipData`, and read-only URI grant.
- PDF rendering, cache IO and provider writing run on the IO dispatcher.
- One export at a time; stale / duplicate callbacks cannot consume a new request.
- Each picker has a distinct `web-export:<UUID>` registry key, separate from
  automatic Diagnosis PDF / text exports. Activity recreation reconnects it.
- Navigation cancels preparation before delivery. Once a picker is launched,
  it owns its original frozen bytes even if the displayed page changes.
- Only id / format / locale / launch marker enter SavedStateHandle. No raw
  snapshot, export bytes, credentials or private network data are saved there.
- A restored process without bytes reports expiry and requires a new user
  action. Consumed picker results clear the launch marker before writing,
  so process restoration during writing cannot wait forever for that result.
- Cancellation, failed provider writes, expired state and absent / rejected
  share handlers do not change the check outcome or History.
- Share cache files use distinct immutable UUID directories and scoped
  24-hour cleanup. A later share does not delete the previous reader's file.
  The small cache primitive is shared with existing automatic Diagnosis text
  exports; their filename validation and previous size behavior are preserved.
  The legacy automatic Diagnosis PDF implementation is untouched.

### Review result and minimal correction

- All four live / saved sources use one allowlisted document; TXT / Copy,
  Markdown and PDF do not have separate raw-data privacy filters. Restored
  Schema 1 data is read through the existing resolver; the saved ID is checked
  at the screen boundary. Export has no resolver, HTTP, TLS, analyzer or
  History-write dependency.

  PDF input. Content-Type is a closed set of standard media types with all
  parameters removed; custom MIME tokens cannot carry private free text.
  URL userinfo / nonroot path / query / fragment / Location, DN / SAN and
  network identifiers remain omitted or explicitly redacted.
- **One privacy defect was reproduced and fixed:** the syntactic hostname
  policy did not reject the local suffix `.localdomain`; the negative fixture
  `printer.localdomain` failed before the fix. The mapper now also rejects
  `.localdomain` and the reserved example suffix `.example`. Helper coverage
  is expanded and a new full TLS / Website document regression checks both
  languages, TXT and Markdown (the native PDF consumes the same document).
  `example.com` and valid public selected hosts / ports remain preserved.
  This is a correction to policy 1 implementation, not a new format, lookup,
  public-suffix service, DNS query or detection algorithm.
- No other blocking defect was found. Failure / unknown / trust / hostname
  outcomes and observed timings are retained; proxy/PAC HTTP and direct TLS
  paths remain distinct. Missing, unmeasured and redacted fields are not
  presented as success. Local-name eligibility remains syntactic, so the
  explicit review-before-sharing warning still applies; this is not anonymity.
- SAF correlation, cancellation, stale callbacks, single-flight ownership,
  Activity recreation and process-restored expiry were traced end to end.
  OutputStream / PDF resources are closed; rendering / cache / provider IO
  are off Main. UUID-scoped immutable shares and read-only content URI grants
  preserve earlier recipients' files. Navigation never starts another probe.
- The small text-cache extraction preserves its original validation, TTL,
  scope and size behavior. Existing automatic Diagnosis Copy / text / PDF
  delivery is not redesigned. Existing tests and Task 176 device regressions
  cover those paths. The legacy automatic PDF implementation remains outside
  this fix; B4 does not silently route web exports through it.
