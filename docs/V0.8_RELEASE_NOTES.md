# LinkBeacon v0.8.0

LinkBeacon v0.8.0 adds focused SSL/TLS and website-access diagnostics while
keeping results local, evidence-based, and deliberately conservative.

## Highlights

- SSL/TLS Check with system-trust validation and certificate details.
- Website Diagnostics using staged DNS, TCP, direct TLS, and HTTPS evidence.
- Local, versioned TLS and Website History snapshots.
- English and Simplified-Chinese presentation.

## SSL/TLS Check

SSL/TLS Check inspects a user-selected TLS endpoint. It reports the negotiated
protocol, system-trust outcome, certificate chain, validity period, names, and
other available certificate evidence. The result explains what was observed
without turning one check into a general security score or vulnerability claim.

The check uses the Android system trust configuration. A failed handshake or
trust validation is reported as evidence from that connection attempt; it does
not prove a server-wide outage or identify one definitive root cause.

## Website Diagnostics

Website Diagnostics performs a staged, user-initiated check:

1. Normalize and safely present the target.
2. Resolve DNS.
3. Test TCP connectivity.
4. Inspect direct TLS when applicable.
5. Perform an HTTPS request and follow the bounded redirect policy.

The report distinguishes direct TLS evidence from proxy-aware HTTP evidence and
retains partial results when later stages cannot complete. VPN, proxy, Private
DNS, and Fake-IP observations are context, not automatic fault declarations.

## Local History and Privacy

- One completed SSL/TLS Check creates at most one `TLS_CHECK` History record.
- One completed Website Diagnostics run creates at most one
  `WEBSITE_DIAGNOSTIC` History record.
- Both snapshot formats use schema version 1.
- Opening a saved result restores the captured snapshot without network I/O or
  re-running analysis.
- URL user information, query values, fragments, authorization data, cookies,
  and sensitive response headers are not retained as diagnostic history.
- Results stay on the device and are not uploaded by LinkBeacon.

## Compatibility

- Requires Android 12 or later (`minSdk 31`).
- Existing installations can upgrade in place without clearing local data.
- Room remains version 5; v0.8.0 adds no database migration.
- Existing History, Device Center profiles, Favorites, Custom Names, Device
  Types, Notes, Wake-on-LAN settings, and observation metadata remain compatible.

## Current Limitations

- No vulnerability scanning, security rating, certificate pinning audit, cipher
  suite enumeration, banner collection, HTTP/3, or QUIC diagnostics.
- No Report/PDF/Share or Automatic Diagnosis integration for these two tools.
- No Port Scan-to-TLS shortcut or Device Detail integration.
- No Wi-Fi Analyzer in v0.8.0.
- Results describe the tested path and moment; they do not prove every aspect of
  a remote service or network.
