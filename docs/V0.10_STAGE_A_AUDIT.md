## Read-only review findings and remediation

| Finding | Risk | Stage A action |
| --- | --- | --- |
| Text share deletes every previous TXT/MD file and reuses names | Recipient URI becomes unreadable or changes contents | Immutable UUID-scoped UTF-8 snapshots; expire only owned, day-old files |
| SAF and text share writes execute on the main thread | Slow document providers can freeze UI | IO dispatcher; retained single-flight SAF ownership; no Activity retained during writes |
| Card heights match but title/description slots and icons do not | One/two-line bilingual labels misalign | Shared card implementation, measured shared title slots (no forced blank line for short Chinese labels), font-aware column fallback |
| Device Center lacks the scanner's identity explanation | Saved names may be mistaken for observed identities; unknown may imply failure | Reuse current-observation semantics and bilingual limitations; wrap count header |
| History write errors are silently swallowed | Completed diagnosis looks saved even when local persistence failed | Typed opt-in save outcome; completed diagnostic remains valid and exportable; show localized failure feedback |
| Markdown escaping omits list/rule punctuation | Network/user text can change document structure | Escape data punctuation; preserve formatter-owned section and bullet markers |
| Existing CI/tests omit text SAF lifecycle and layout validation | Build success could be mistaken for acceptance | Add targeted unit and device integration coverage; report remaining gates separately |

## Architecture and compatibility review

- LAN identity filters use **current scan** network identity data and known local/gateway roles. Custom names/favorites do not establish observed identity; persisted unseen profiles are not current discoveries. No new discovery evidence, Last Seen writes, range or timeout changes.
- TXT/Markdown consume the same frozen localized presentation used by Copy/PDF. Export is user initiated; it does not run probes, reanalyze or write History. Old schema-2/3 reports remain displayable; unstructured legacy prose is not translated or invented.
- SAF state stores only a correlation ID/format; sensitive bytes remain in the retained ViewModel. Activity recreation can complete the original request; process death expires it rather than exporting a different report. Callback feedback strings are captured from the Activity's AppCompat locale (important on API 31/32); the IO callback retains only strings and Application context, not the Activity.
- History failure feedback is live metadata, not a diagnosis finding or persisted schema field. Existing record-only callers keep supplementary-history semantics; no migration or retry that could duplicate a report.
- Diagnosis wording changes explain observations, uncertainty and next checks without changing Analyzer rules. VPN/Fake-IP/non-response are not reclassified as faults.
- Bounded LAN list performance is not classified as a defect without measurements. No speculative database/index/recomposition rewrite.
